## 🛠️ Lingkungan Pengembangan

Proyek ini dikembangkan dan dipelihara menggunakan perangkat keras dan perangkat lunak berikut:
* **Perangkat:** Raspberry Pi 5
* **Sistem Operasi:** Raspberry Pi OS (Linux CLI)
* **Alat bantu:** Git & GitHub CLI (`gh`)

---

## 🚀 Alur Kerja Pembaruan (CLI)

Untuk memperbarui konten situs dari terminal Raspberry Pi 5, gunakan urutan perintah berikut:

1. **Tarik pembaruan terbaru (jika ada):**
   ```bash
   git pull origin main
   ```

2. **Tambahkan file yang diubah atau dibuat:**
   ```bash
   git add .
   ```

3. **Simpan perubahan dengan pesan commit:**
   ```bash
   git commit -m "Deskripsi singkat pembaruan"
   ```

4. **Unggah perubahan ke GitHub:**
   ```bash
   git push origin main
   ```
